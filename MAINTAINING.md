# Profile and portfolio

This repository publishes the GitHub profile and portfolio site together. GitHub Pages is live from `main /docs` at <https://enrikr2002.github.io/EnrikR2002/>; each project page links back to its source when that source is public.

| File or folder | Purpose |
| --- | --- |
| `README.md` | Generated GitHub profile page |
| `docs/` | Generated static website and 26 project detail pages |
| `portfolio.json` | Curated public profile, project, and experience content |
| `scripts/build.mjs` | Generates both published surfaces and site pages |
| `scripts/check.mjs` | Checks generated pages, links, project coverage, and interactions |
| `site/` | Website styles and browser interactions |

## Where information lives

The Notion **Career & Portfolio** hub and **Project Inventory** are the broader working record. The inventory can include private and non-GitHub work. `portfolio.json` is the deliberately curated public subset; it generates both the README and website. Keep private repository URLs, personal contact details, credentials, and confidential material out of public files. Describe work accurately as built, prototype, foundation, research, or coursework, and make team contributions clear. The original vector illustrations are conceptual artwork, not screenshots of running products.

## Update workflow

1. Check the current Notion project record and repository evidence before changing a claim. Update the Notion inventory when project status or source information changes.
2. Add or revise the public-facing fields in `portfolio.json`. Include a project in the public site only when its description and visibility are appropriate to publish.
3. With Node.js 22 or later, run:

   ```sh
   npm run build
   npm run check
   ```

4. Review the generated `README.md` and affected pages under `docs/`. Confirm project status, demos, source links, and privacy boundaries.
5. When the user asks to update the published portfolio, commit the source and generated files to `main`. GitHub Pages deploys from `main /docs`; the profile and site already share the data and link to one another.
6. Update the Notion portfolio tracking page with the published change or the remaining next step.
