Instagram Reels Metadata Scraper

Extracts accessible Reel metadata through a CLI, browser dashboard, and Windows launcher, with caching and optional thumbnail OCR.

Back to the index ←

What I worked on

  • Built a shared scraping core with CLI and Flask interfaces, SQLite caching, retries, rate handling, and CSV/TSV export.
  • Added optional thumbnail OCR and Windows executable packaging with a first-run setup wizard.

Where it stands

Executable packaging and setup are documented. Current Instagram compatibility was not exercised.
