Insertion Physique Studio

Interactive 3D physique studio for exploring muscle insertions, skeletal proportions, development, poses, and body measurements.

View source ↗Back to the index ←

What I worked on

  • Built a 3D physique studio with 24 adjustable traits, 12 poses, side-by-side comparisons, shareable configurations, and PNG export.
  • Integrated anatomical asset processing, surface-based measurements, and rendering that reduces GPU work when the scene is idle.

Where it stands

Functional application documented in the repository. Anatomical sculpt and atlas come from credited third parties; model outputs are illustrative.

My part

Repository owner; application built around credited external anatomy assets.
