EnrikDraw

Adds cloud document storage and autosave to Excalidraw drawings that remain editable inside Notion embeds.

Open app ↗View source ↗Back to the index ←

What I worked on

  • Built an Excalidraw wrapper with persistent drawing URLs, Supabase storage, autosave, and editable Notion embeds.
  • Implemented a protected management page and token-checked drawing access; kept drawing data portable in Excalidraw’s native format.

Where it stands

Repository lists a Vercel homepage. Current uptime was not tested; the drawing editor itself is Excalidraw.

My part

Repository owner; wrapper and persistence layer over Excalidraw.
