WorkJam to Google Calendar

Syncs WorkJam shifts to a dedicated Google Calendar, updating changed events and removing cancelled shifts it manages.

Back to the index ←

What I worked on

  • Built an idempotent WorkJam-to-Google Calendar sync with OAuth, session renewal, changed/cancelled shift reconciliation, and dry-run mode.
  • Added container scheduling, encrypted state support, and failure notifications while preserving unrelated calendar events.

Where it stands

Repository documents deployment paths and 30 offline reconciliation tests. Current live scheduling was not tested.
